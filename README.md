# Generador de Referencias APA

Aplicación sencilla en Java para la Actividad Formativa 2 de Programación Orientada a Objetos.

Recibe los datos de un libro (autor, año, título y editorial), arma la cita en formato APA y genera la bibliografía ordenada alfabéticamente por autor.

## Estructura
- **Referencia.java**: clase molde de un libro. Atributos privados, constructor y método `formatoAPA()`.
- **Bibliografia.java**: guarda varias referencias en una lista. Métodos `agregar()`, `ordenar()`, `mostrar()` y `getTotal()`.
- **Main.java**: programa principal. Crea los objetos y prueba los métodos.

## Cómo ejecutarlo
Abrir el proyecto en Eclipse (u otro IDE de Java) y correr `Main.java`.
